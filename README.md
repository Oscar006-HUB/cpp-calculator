# C++ Calculator

Beginner C++ console programs: a four-function calculator plus small pointer and BMI exercises.

## Contents

| Path | Description |
|------|-------------|
| `main.cpp` | Switch-based calculator (`+ - * /`) on two integers |
| `OOP/main.cpp` | Pointer basics exercise |
| `index calculator/main.cpp` | BMI calculator (work in progress, does not compile yet) |

## Build

```bash
g++ main.cpp -o calculator
./calculator
```
